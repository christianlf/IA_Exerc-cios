# 🧠 Exercícios de Inteligência Artificial

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![FIAP](https://img.shields.io/badge/Instituição-PUC--Campinas-red.svg)](https://www.puc-campinas.edu.br/)

Repositório de exercícios práticos e implementações de algoritmos de **Inteligência Artificial** desenvolvidos durante o curso de **Sistemas de Informação** na PUC-Campinas.

## 📚 Conteúdo

### 🔍 Módulo 1: Algoritmos de Busca
Implementações de algoritmos clássicos de busca em IA:
- **Busca Gulosa** (`BuscaGulosa.py`)
- **Busca A*** (`Buscar_estrela1.py`)
- **Exercícios práticos** de aplicação

**Conceitos abordados:**
- Heurísticas
- Busca informada vs. não-informada
- Complexidade de algoritmos de busca

### ⚙️ Módulo 2: Otimização
Técnicas de otimização e resolução de problemas complexos:
- **MLRose** - Otimização com algoritmos genéticos
- **Problema de agendamento de voos** (`flights.txt`)
- Algoritmos de otimização combinatória

**Conceitos abordados:**
- Algoritmos genéticos
- Hill Climbing
- Simulated Annealing
- Otimização combinatória

### 🎛️ Módulo 3: Lógica Fuzzy
Implementações de sistemas de lógica difusa:
- **Scikit-Fuzzy** (`skfuzzy.py`)
- Sistemas de inferência fuzzy
- Controle fuzzy

**Conceitos abordados:**
- Conjuntos fuzzy
- Regras de inferência
- Defuzzificação
- Aplicações em sistemas de controle

### 🎓 Exercícios FIAP
Exercícios específicos e desafios propostos pela instituição.

### 💪 Treinamento Prático
Scripts de prática e exercícios complementares:
- `treino1.py` - Fundamentos
- `treino2.py` - Aplicações avançadas

## 🛠️ Tecnologias Utilizadas

- **Python 3.8+**
- **MLRose** - Otimização e algoritmos genéticos
- **Scikit-Fuzzy** - Lógica fuzzy
- **NumPy** - Computação numérica
- **Matplotlib** - Visualização de dados

## 🚀 Como Usar

### Pré-requisitos

```bash
python --version  # Python 3.8 ou superior
```

### Instalação

1. **Clone o repositório:**
```bash
git clone https://github.com/christianlf/IA_Exerc-cios.git
cd IA_Exerc-cios
```

2. **Instale as dependências:**
```bash
pip install -r requirements.txt
```

### Executar exercícios

**Módulo 1 - Busca:**
```bash
python modulos/modulo-01-busca/BuscaGulosa.py
python modulos/modulo-01-busca/Buscar_estrela1.py
```

**Módulo 2 - Otimização:**
```bash
python modulos/modulo-02-otimizacao/mlrose.py
```

**Módulo 3 - Lógica Fuzzy:**
```bash
python modulos/modulo-03-logica-fuzzy/skfuzzy.py
```
